# Brand assets

The README uses local copies so its logos do not depend on third-party image hosting.
Light and dark variants are selected using GitHub's supported `picture` markup.

- Nace: [black](https://console.nace.ai/brand/nace-logo-black.svg) and
  [white](https://console.nace.ai/brand/nace-logo-white.svg), from Nace's brand assets.
- DuckDB: the official inline [light](https://github.com/duckdb/duckdb-web/blob/main/images/designmanual/DuckDB_inline-lightmode.svg)
  and [dark](https://github.com/duckdb/duckdb-web/blob/main/images/designmanual/DuckDB_inline-darkmode.svg)
  variants from the DuckDB website's design manual assets.

The SVG artwork is unmodified. These marks identify the integration and remain the
